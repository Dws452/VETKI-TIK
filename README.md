# TIK — Threat Intelligence Kernel

Учебный веб-проект на Node.js, Express, MongoDB/Mongoose и EJS. Приложение помогает вести учебный каталог угроз, IOC (индикаторов компрометации), просматривать сводку и создавать записи.

## Возможности
- Главная панель с метриками и последними событиями.
- Каталог угроз: просмотр, поиск, фильтр по уровню риска и добавление записи.
- Каталог IOC: IP-адреса, домены, URL и хеши.
- Страницы аналитики и отчёта.
- Регистрация, вход, выход; пароли хранятся только в виде bcrypt-хеша.
- Сессии в MongoDB, счётчик посещений и middleware для закрытых страниц.
- Демонстрационный режим с тестовыми данными, если MongoDB ещё не запущена.

## Запускать как
1. Установить Node.js 18+ и MongoDB 6+.
2. Выполнить `npm install`.
3. Скопировать `.env.example` в `.env` и при необходимости поменять `MONGODB_URI` и `SESSION_SECRET`.
4. Запустить MongoDB.
5. Выполнить `npm run seed` для добавления демонстрационных угроз и IOC.
6. Запустить `npm start` и открыть `http://localhost:3000`.

Если MongoDB недоступна, сайт откроется в демонстрационном режиме (без сохранения регистрации и новых записей между перезапусками). Для полноценной работы включите MongoDB!!! 

## Учётная запись
Зарегистрируйте пользователя через кнопку «Войти / Регистрация». Готовых паролей в репозитории нет и не будет!!! 

## Структура общая
- `app.js`, `bin/www` — запуск и настройка Express.
- `routes/` — маршруты страниц и действий.
- `models/` — схемы Mongoose.
- `middlewares/` — авторизация и глобальные данные шаблонов.
- `views/` — EJS-шаблоны.
- `public/` — CSS, JavaScript и SVG-иллюстрации.
- `scripts/seed.js`, `data/` — заполнение базы тестовыми данными.
